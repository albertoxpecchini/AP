# Immagini per «Il Gattopardo» (/gattopardo)

La pagina funziona già senza foto: ogni cornice mancante mostra un placeholder
viola con icona. Per completarla, basta inserire qui i file con questi nomi
esatti (formato `.jpg`):

- `copertina.jpg` — copertina del libro (verticale 4:5) · hero
- `autore.jpg` — ritratto di Giuseppe Tomasi di Lampedusa (verticale 4:5)
- `sicilia.jpg` — palazzo nobiliare / paesaggio siciliano (orizzontale 3:2)
- `finale.jpg` — un tramonto sulla Sicilia (orizzontale 3:2)
- `chiusura.jpg` — paesaggio siciliano al tramonto (banner di chiusura) · molto largo

Suggerimento: immagini di pubblico dominio o con licenza libera
(es. Wikimedia Commons), oppure fotogrammi del film di Visconti se i diritti lo
consentono. Le foto vengono ritagliate in `cover`.
