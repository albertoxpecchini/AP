# Immagini per «Gente di Dublino» (/dubliners)

La pagina funziona già senza foto: ogni cornice mancante mostra un placeholder
viola con icona. Per completarla, basta inserire qui i file con questi nomi
esatti (formato `.jpg`):

- `copertina.jpg` — copertina del libro (verticale 4:5) · hero
- `joyce.jpg` — ritratto di James Joyce (verticale 4:5)
- `dublino.jpg` — una via / scorcio di Dublino (orizzontale 3:2)
- `dublino-2.jpg` — Dublino d'epoca, inizio Novecento (orizzontale 3:2)
- `neve.jpg` — paesaggio innevato (banner di chiusura, «I morti») · molto largo

Suggerimento: immagini di pubblico dominio o con licenza libera
(es. Wikimedia Commons). Le foto vengono ritagliate in `cover`.
